# Pre-Routing Check

Run this before starting any coding workflow.

```text
Execution route: Direct GPT | Spec→Cheap Implementer→GPT Eval | Split First
Why:
- scope: small | medium | large
- risk: low | medium | high
- clarity: clear | medium | unclear
- review width: narrow | broad
- retry likelihood: low | medium | high
Decision: <one sentence>
```

If this cannot be filled in confidently, the task should be split smaller before using the cost-control workflow.
