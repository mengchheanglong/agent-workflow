## Cross-video synthesis

1. **Friction is usually invisible.** Blank forms, hidden content, dropdowns, price ranges, mental math, manual typing, and unhelpful search all feel small but compound into abandonment.
2. **Trust beats pressure.** UX Peak repeatedly distinguishes conversion design from dark patterns: honest proof, transparent pricing, cancellation clarity, and real policy information outperform vague persuasion long-term.
3. **Senior design is contextual.** The “right” control depends on frequency, precision, risk, user familiarity, device, and stage in the journey.
4. **Visual polish follows hierarchy.** Shadows, glass, 3D, gradients, and animation only work after information priority and usability are clear.
5. **Figma prototypes should encode state.** Use frames/components/variants, consistent names, auto layout, and smart animate so interactions can be inspected and handed off, not just admired.
