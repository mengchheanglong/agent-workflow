# Component Galleries & Marketplaces

Curated sources for finding specific components and blocks.

## 21st.dev
- **URL:** https://21st.dev
- **Description:** Community-driven component marketplace. Browse by category (Heros, Features, AI Chat, Buttons, Testimonials, Pricing, Text, Shaders).
- **Use for:** Finding specific animated components with live preview and code.
- **Stack:** React + Tailwind CSS + Framer Motion (most components)
- **Categories:** Heros, Features, AI Chat Components, Calls to Action, Buttons, Testimonials, Pricing Sections, Text Components, Shaders, Dependencies, Tags.

## Refero
- **URL:** http://styles.refero.design
- **Description:** 2,000+ AI-readable design systems from leading product websites. Extract colors, typography, spacing, components, and DESIGN.md.
- **Use for:** Getting design system tokens from real products (Apple, Stripe, Notion, Linear, etc.).
- **Output:** DESIGN.md files for AI agents (Cursor, Claude Code, Codex, v0, Lovable).

## Design.md (designmd.me)
- **URL:** http://designmd.me
- **Description:** Extract the design system behind any website. Paste a URL → get structured DESIGN.md, live HTML preview, and Figma import.
- **Use for:** Converting any website into a structured design system.
- **Pipeline:** URL → DESIGN.md → HTML preview → Figma import.

## Design.md Supply
- **URL:** http://designmd.supply
- **Description:** Supply of style guides generated from Context.dev. Brand identity, screenshots, and live markup shaped into Google DESIGN.md documents.
- **Use for:** Getting pre-extracted design systems for major brands (Apple, Microsoft, Google, Meta, Tesla, Nike, Stripe, etc.).
- **Brands available:** Apple, Microsoft, Google, Meta, Tesla, Broadcom, TSMC, Berkshire Hathaway, Eli Lilly, JPMorgan, Walmart, Visa, UnitedHealth, ExxonMobil, Costco, Netflix, Adobe, Salesforce, PepsiCo, Nike, McDonald's, Toyota, Sony, IBM, Intel, AMD, Qualcomm, Airbnb, Uber, Shopify, Stripe, Block, PayPal, Coinbase, Dropbox, Atlassian, GitHub, Linear, Notion, Figma, OpenAI, Anthropic.

## Open Design
- **URL:** http://open-design.ai
- **Description:** Open-source vibe design workspace. 152+ design systems, 21+ coding agent adapters, BYOK, Apache-2.0.
- **Use for:** Local design system extraction and prototyping.
- **Stack:** Works with Claude Code, Codex, Cursor, Gemini CLI, OpenCode, Qwen, Grok, Hermes, etc.

## Neuform
- **URL:** http://neuform.ai
- **Description:** AI HTML Landing Page Builder and Remix Templates. Turns prompts into AI HTML landing pages, remix templates, and reusable DESIGN.md files.
- **Use for:** Quick landing page generation from prompts.

## TypeUI
- **URL:** http://typeui.sh
- **Description:** Build and grow websites using AI with Codex. Design skills, UI prompts, brand kits, and shared design system through MCP.
- **Use for:** Connecting design systems to AI coding tools (Codex, Claude, Cursor).
- **Products:** TypeUI Creative (design skills + UI prompts), TypeUI Insights (analytics).
